LayoutRecall: Preserving Appearance in Multi-Round 3D Layout-Controlled Image Editing

LayoutRecall：在多轮3D布局控制的图像编辑中保持外观

Yankuan Chi, Xin Lin, Baihan Yang, Yuheng Liu, Jason Li 等 (6 位作者)

核心贡献: 提出LayoutRecall多轮编辑器，通过存储和重用3D框局部坐标系中的外观信息，解决物体被遮挡或移出视野后重新出现时的外观恢复问题；同时构建了多轮3D布局控制图像编辑基准LayoutLoop。
方法: 将图像潜在表示存储在3D框表面（Box-Surface Latent Memory），并在目标视角下沿射线检索；通过几何对齐记忆条件（Geometry-Aligned Memory Conditioning）将检索到的token以目标视角位置、共享框局部嵌入和对象级注意力供给FLUX.2编辑器；引入对应损失（correspondence loss）促使编辑器在去噪过程中关注匹配的观测。
关键发现: 在LayoutLoop基准和真实场景数据上的大量实验验证了该方法能够有效恢复物体外观，在多轮编辑中保持外观一致性。
查看原文摘要

3D layout-controlled image editing gives users explicit control over object placement and camera viewpoint. In a sequence of edits, however, the latest image can lose the appearance of an object when it is occluded or leaves view. The target layout specifies where the object should reappear, while its appearance must be recovered from earlier observations. We introduce LayoutRecall, a multi-round editor that stores and reuses appearance in the local coordinate systems of 3D boxes. Box-Surface Latent Memory retains image latents on box faces and retrieves them along rays in the target view. Geometry-Aligned Memory Conditioning supplies the retrieved tokens to a FLUX.2 editor using target-view positions, shared box-local embeddings, and object-wise attention. A correspondence loss encourages the editor to attend to matching observations during denoising. We also introduce LayoutLoop, a multi-round 3D layout-controlled image editing benchmark with calibrated layouts and designed revisits. We conduct extensive experiments on LayoutLoop and real-scene data to verify the ability of our method. The project page is at https://ykchizs.github.io/layoutrecall.github.io/.

SceneDesigner++: A Unified 9-DoF Pose Control Framework for T2I and T2V Generation

SceneDesigner++：面向T2I和T2V生成的统一9自由度姿态控制框架

Xincheng Shuai, Zhenyuan Qin, Henghui Ding, Dacheng Tao

核心贡献: 提出了一个统一的9自由度姿态控制框架SceneDesigner++，同时适用于文本到图像（T2I）和文本到视频（T2V）生成，并构建了高质量数据集ObjectPose9D++和评估基准T2IVPoseEval。
方法: 构建了包含精确姿态标注的图像和视频数据集ObjectPose9D++用于训练。框架结合绝对和相对姿态编码策略：绝对姿态编码利用CNOCS图序列提供逐帧的显式9自由度姿态引导；相对姿态编码（VPRoPE）将相对姿态信息融入旋转位置嵌入以建模帧间姿态过渡。为每个注意力头引入可学习的正交变换以捕获互补几何关系并保持特征范数稳定。采用两阶段训练策略分别学习绝对和相对姿态编码，并支持与独立训练相机控制模块集成。
关键发现: 大量实验表明，SceneDesigner++在姿态保真度和运动质量上持续优于相同骨干网络的基线方法，并支持对象与相机运动的单独或联合控制。
查看原文摘要

Precise 9-DoF pose control is essential for visual content generation, enabling users to specify object location, size, and orientation in 3D space. However, existing methods typically focus on either text-to-image (T2I) or text-to-video (T2V) generation, with limitations in pose controllability and temporal coherence. We present SceneDesigner++, a unified framework for 9-DoF pose control across both T2I and T2V generation. We construct ObjectPose9D++, a dataset containing high-quality images and videos with accurate pose annotations. Trained on ObjectPose9D++, SceneDesigner++ combines absolute and relative pose encoding strategies to decouple frame-wise spatial grounding from inter-frame motion modeling. Specifically, absolute pose encoding leverages CNOCS map sequences to provide explicit, frame-wise 9-DoF pose guidance. Meanwhile, our relative pose encoding, termed VPRoPE, incorporates relative pose information into rotary position embeddings to explicitly model inter-frame pose transitions, thereby promoting temporally coherent object motion. A learnable orthogonal transformation is further introduced for each attention head, allowing different heads to capture complementary geometric relationships while preserving input feature norms to promote training stability. We further adopt a two-stage training strategy to learn the absolute and relative pose encoding mechanisms separately. Benefiting from this lightweight and decoupled design, SceneDesigner++ also supports integration with an independently trained camera-control module, enabling separate or joint control over object and camera motion. Finally, we introduce T2IVPoseEval, a benchmark for evaluating diverse object poses and motion patterns in both T2I and T2V tasks. Extensive experiments demonstrate that SceneDesigner++ consistently outperforms same-backbone baselines in pose fidelity and motion quality.

Semantic State Reading for Joint Image-Semantic Diffusion Transformers

Guanxi Lai, Zixuan Li, Zhiwei Li, Qi Li

核心贡献: 论文提出语义状态读取（SSR）方法，在扩散Transformer中同时建模图像潜变量、全局CLS语义令牌和局部patch语义状态，从而在去噪全过程中保持全局上下文与局部空间结构的可访问性，显著加速训练并提升生成质量。
方法: SSR联合去噪图像潜变量、编码图像级上下文的全局CLS令牌以及保留空间对应关系的紧凑patch状态。该方法采用两种不同的读取路径：局部状态在输入端与对应的图像令牌融合，而独立的投影则将当前全局状态注入每个Transformer块。通过这种方式，全局与局部语义范围在整个去噪过程中始终可被访问。
关键发现: 消融实验表明局部状态建模与重复全局读取具有互补收益，语义轨迹干预可在固定类别标签下改变图像布局。在ImageNet 256×256上，SiT-XL/2结合SSR分别以100倍、40倍和2倍更少的训练迭代达到或超过SiT、REPA和REG的参考FID。SSR在200万次迭代时无引导FID为1.78，仅用无分类器引导时FID为1.34；结合无分类器引导与自引导在100万次迭代时FID达1.31，为主对比表中的最佳FID。

Pretrained visual representations improve diffusion-transformer training, yet exploiting both global context and local spatial structure requires deciding which semantic states to model and how to access them. We introduce Semantic State Reading (SSR), which jointly denoises image latents, a global CLS token encoding image-level context, and a compact patch state preserving spatial correspondence. SSR couples this global-local modeling with distinct reading paths: local states are fused with corresponding image tokens at the input, while independent projections inject the current global state into every transformer block. Both semantic scopes thus remain accessible throughout denoising. Ablations show complementary benefits from local-state modeling and repeated global reading, and semantic-trajectory interventions alter image layout under a fixed class label. On ImageNet $256 \times 256$, SiT-XL/2 with SSR reaches or surpasses the reference FIDs of SiT, REPA, and Representation Entanglement for Generation (REG) with $100\times$, $40\times$, and $2\times$ fewer training iterations, respectively. SSR achieves unguided FID 1.78 at 2M iterations and FID 1.34 with classifier-free guidance alone. Combining classifier-free guidance with autoguidance yields FID 1.31 at 1M iterations, achieving the best FID in our main comparison table.

Exploring the Design Factors of Pixel-space Diffusion

探索像素空间扩散模型的设计因素

Mang Ning, Le Zhang, Albert Ali Salah, Itir Onal Ertugrul, Jintao Zhang

核心贡献: 本文通过系统研究模型架构、表示和频域三个关键设计因素，提出了EiT模型，在像素空间扩散中实现了优于JiT的生成质量，并可无缝扩展到视频扩散任务。
方法: 受去噪自编码器通过瓶颈进行去噪的启发，构建了沿通道维度显式压缩的U形像素扩散Transformer。从表示角度分析了像素和潜在扩散Transformer在层与时间步上的三阶段表示动态。从频域角度建立了像素空间与频率空间扩散的等价性。
关键发现: 在ImageNet 256×256和512×512上，EiT的FID分别为1.61和1.73，优于JiT的1.85和1.99。EiT通过通道瓶颈和增加网络深度自然实现了更早的去噪和更长的基提升阶段，从而获得更好的生成效果。此外，EiT可简单扩展至视频像素扩散，在Kinetics-600上FVD优于视频潜在扩散。

In this paper, we introduce EiT by exploring the key design factors of pixel-space diffusion from three perspectives: model architecture, representation, and frequency domain. Inspired by Denoising Autoencoders (DAE) which perform denoising through a bottleneck, we construct a U-shaped pixel diffusion transformer that performs explicit compression along the channel dimension. In terms of representation, we find that both pixel and latent diffusion transformers exhibit a three-stage representation dynamics across layers and timesteps: denoising/local feature expansion, basis lift-up, and posterior projection. Moreover, earlier denoising and a longer basis lift-up stage are associated with better generation, which EiT naturally achieves through its channel bottleneck and increased network depth. From the frequency perspective, we establish the equivalence between pixel-space and frequency-space diffusion when keeping the network operating in pixel space. On ImageNet $256\times256$ and $512\times512$, EiT consistently outperforms JiT (Just image Transformers) in generation quality. Specifically, our EiT achieves better FID than JiT: 1.61 vs. 1.85 at $256\times256$, and 1.73 vs. 1.99 at $512\times512$. Remarkably, EiT can be seamlessly applied to video pixel diffusion by simply extending the patch size to temporal dimension and outperforms video latent diffusion in FVD evaluated on Kinetics-600 (resolution 256), under comparable total network parameters. Code is available at https://github.com/forever208/EiT

ScanAR: Parallel Row-Scan Decoding for Efficient Image Generation in Unified Autoregressive Models

ScanAR：面向统一自回归模型高效图像生成的并行行扫描解码

Jingen Qu, Xi Chen, Yingbo Tang, Xinghang Li, Tao Kong

核心贡献: 提出ScanAR，一种仅通过重新定义视觉token前驱关系的并行行扫描解码方法，将视觉解码深度从H×W降至H+W，在不改变骨干网络、词表或输出头且不增加参数的前提下大幅加速统一自回归模型的图像生成。
方法: ScanAR保留首行视觉token从左到右的常规自回归生成，后续每一行在单个并行步骤中生成，每个token由上一行垂直对齐的token预测得到，非视觉token仍遵循标准自回归规则。该方法不修改分词器、预测头或模型接口，支持从头训练和轻量级后训练两种方式。
关键发现: 在Emu3.5-Image-34B上，ScanAR后训练取得82.36的GenEval分数，为同数据训练的后训练加速方法中最佳，相同推理设置下生成512×512图像比栅格解码快13.8倍；在ImageNet上从头训练时各模型规模下吞吐量最高，FID与栅格LlamaGen相当；在34B Xiaomi-Robotics-U0模型上保持了具身场景生成、图文交错生成和视频生成的总体质量。
查看原文摘要

Unified multimodal autoregressive (AR) models represent text and images in one token sequence and generate all modalities with a shared next-token prediction head. Their image generation, however, decodes an $H\times W$ visual grid token by token in raster order, which takes $HW$ sequential steps and dominates inference time. Existing acceleration methods for visual AR generation either change the tokenizer, the prediction head, or the model interface, or keep the model but cannot reach high parallelism without losing quality, so they do not carry over to unified AR models. We propose ScanAR, a row-scan parallel decoding method that only redefines the predecessors of visual tokens. The first visual row is generated from left to right as usual, and each later row is generated in a single parallel step, with every token predicted from the vertically aligned token of the previous row. Nonvisual tokens keep the standard autoregressive rule. ScanAR reduces the visual decoding depth from $HW$ to $H+W$ without changing the backbone, vocabulary, or output head and without adding parameters, and it supports both training from scratch and lightweight post-training. On Emu3.5-Image-34B, ScanAR post-training reaches a GenEval score of 82.36, the best among post-training acceleration methods trained on the same data, and generates $512\times512$ images $13.8\times$ faster than raster decoding under the same inference setting. On ImageNet, ScanAR trained from scratch has the highest throughput at every model size with FID comparable to raster LlamaGen. On the 34B Xiaomi-Robotics-U0 model, ScanAR preserves the overall quality of embodied scene generation, interleaved image-text generation, and video generation.
